# 전북천년명가 모션그래픽 — 콘티 (9:16 · 20.0s · 30fps)

**콘셉트:** "시간이 증명한 이름" — 30년을 지켜온 가게들이 100년을 향해 가고, 그 이름이 전북천년명가가 된다.
밝은 한지 톤 위에 BI 4색(올리브 그린·머스터드·크림슨·먹)을 쓴 모던 3D 타이포그래피. 한자·금색 래커·붉은 도장 같은 중국풍 요소는 쓰지 않는다.

- 팔레트: 한지 #F3EEE4 · 먹 #211815 · 그린 #93B143 · 옐로 #E7B543 · 레드 #B52D2A
